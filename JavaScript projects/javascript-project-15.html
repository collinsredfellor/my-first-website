Designed with purpose

More than just a theme.

This project combines interactive JavaScript with modern design principles to create a useful, accessible experience.

🌗

Instant theme switching

Move between dark and light appearances instantly. The interface updates without reloading the page.

💾

Preference memory

Your chosen theme is stored in localStorage, so it can remain selected when you revisit or reload the page.

📱

Responsive layout

Navigation, cards, buttons, and content adapt to desktops, tablets, and smaller mobile screens.

✨

Smooth animations

Subtle transitions and floating visual elements add polish without overwhelming the content.

🎨

Centralized color system

CSS custom properties control the colors, backgrounds, borders, and shadows used throughout the website.

♿

Accessibility in mind

Keyboard focus styles, descriptive button labels, readable content, and reduced-motion support improve usability.
