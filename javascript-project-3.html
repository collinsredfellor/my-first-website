How the Loop Works

This is the basic logic behind our multiplication table generator.

for ( let i = 1; i <= 12; i++ ) { result = number * i; } The loop starts at 1. It continues while i is less than or equal to 12. After every repetition, i increases by 1. This allows JavaScript to automatically calculate all twelve multiplication results.
