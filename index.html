About My Journey

I am learning software development by starting with the fundamentals and gradually progressing toward more advanced technologies.

My goal is not simply to learn programming syntax. I want to understand how real-world applications are designed, built, deployed, maintained, and improved.

Every project I create becomes another step in that journey.

The path I am following as I develop my software engineering skills.

  1. Python

  2. HTML

    Learning how websites are structured using semantic HTML.

  3. CSS

    Learning how to design, style, and create responsive websites.

  4. JavaScript

    Learning how to make websites interactive and dynamic.

    Learning servers, APIs, authentication, databases, and application logic.

    Building larger applications and understanding advanced software architecture.

  7. Artificial Intelligence

    Exploring AI systems, machine learning, and intelligent applications.

  9. Startup Building

    Turning technical skills and ideas into real-world products and businesses.
